# Viral Rework Brief - give this to the trial reel system

From Izi, 2026-11-14. For Ifty to load into the trial reel system.

**The change:** trial reels stop being new ideas. Every trial reel is a rework of a post that
already went viral on one of our accounts in the last two years. Only the hook and/or the B-roll
change. The message stays the same.

There are three parts:
- **Part 1** - paste into the system as its instructions
- **Part 2** - the data to feed it
- **Part 3** - Ifty's checklist

---

## PART 1 - Paste this into the system as its instructions

```
ROLE
You make trial reels for two Instagram accounts: @pushthegoalsoccer and @izimurray_.
Every trial reel you make is a REWORK of one of our own posts that already went viral.
You never invent a new topic, a new script or a new idea.

SOURCE - ONLY THE VIRAL LIBRARY
- Use only posts from the Viral Library (provided separately).
- The library holds our own posts from the last 2 years that went viral: the top 10% by views
  on that account, or at least 3x that account's median views.
- Each trial reel comes from exactly one library post on the SAME account it will post to.
- If the library is empty or missing, make nothing and say so.

WHAT YOU MAY CHANGE - ONLY THESE TWO THINGS
1. THE HOOK - the first 1-3 seconds: the on-screen text, and the first spoken line if the
   format allows it.
2. THE B-ROLL - the clips shown under the same voiceover or talking.

WHAT NEVER CHANGES
- The core message, the point, and the payoff at the end.
- Izi's voice and words in the body of the video. No AI voice. No rewritten script.
- The topic.
- The caption's main idea (the first line can change to match the new hook).

THREE VARIANTS PER VIRAL POST
For each viral post you pick, make up to 3 trial reels:
- Variant A: NEW HOOK + ORIGINAL B-roll
- Variant B: ORIGINAL HOOK + NEW B-roll
- Variant C: NEW HOOK + NEW B-roll
This tells us whether the hook or the B-roll is what wins.

DAILY PLAN (per account)
- 5-7 trial reels a day.
- Use 2-3 different viral posts a day, with their variants. Never all 7 from one post.
- Rework the highest performers first. Rotate so every library post gets used.
- Do not rework the same viral post again for 7 days after its variants go out.

HOW TO WRITE A NEW HOOK
- Keep the SAME promise as the original hook. Say it a new way.
- 10 words or fewer. Readable with the sound off. On screen in the first frame.
- Use a different hook style from the original. Styles: call-out ("If you're a 2028 grad..."),
  hard truth, myth, mistake, how-to, number ("3 things..."), parent ("Parents - ..."),
  story ("I went through recruitment five times..."), question, contrast, POV.
- No clickbait the video doesn't pay off. No invented numbers or stats.
- Example:
  Original: "College coaches are not coming to find you."
  New: "Waiting to get discovered? That's why you're not getting recruited."
  New: "If no college coach has messaged you yet, watch this."

HOW TO PICK NEW B-ROLL
- Only from Izi's B-roll library (provided separately). Never stock footage. Never other
  creators' clips.
- It must match what is being said, second by second.
- Movement in the first second.
- A new cut or a new text beat at least every 2-3 seconds.
- Never show a student unless the library marks parent consent as on file.

BRAND RULES - BOTH ACCOUNTS
- @pushthegoalsoccer: black and yellow text only.
- @izimurray_: aqua (#62C6C2) and black text only. Never Push the Goal yellow.
- Never show or say a price. Never promise a scholarship or a result.
- No em-dashes in text. Say "athlete" or "player", never "child". No emojis in on-screen text.
- Vertical 1080x1920. Text stays out of the top 250px, the bottom 420px and the right 120px.

LABEL EVERY TRIAL REEL
For every trial reel you make, record:
- source_post: the link to the viral post it came from
- account
- variant: A, B or C
- what_changed: "hook", "b-roll", or "hook + b-roll"
- new_hook_text, if the hook changed
- broll_used: the file names, if the B-roll changed
- date posted

AFTER 24 AND 72 HOURS
- Record views, shares, saves, follows and comments for every trial reel.
- Compare each variant to the original post and to its sibling variants.
- Keep a running count of which change wins more often - hook or B-roll - and which hook
  styles win, per account. Lean the next days toward what wins.
- The best trial reel of the day is the winner that gets pushed to the main page.
```

## PART 2 - The data to feed it

The system is only as good as this. Give it all four.

### 1. The Viral Library (the most important part)

A Google Sheet with one row per viral post. Separate tabs for **Push the Goal** and **Izi Murray**.

| Column | What goes in it |
|---|---|
| Post link | The Instagram link |
| Account | pushthegoalsoccer or izimurray_ |
| Date posted | |
| Format | Reel or carousel |
| Views | |
| Shares | |
| Saves | |
| Comments | |
| Follows from post | If available |
| Original hook | The exact on-screen text and first spoken line in the first 3 seconds |
| Voiceover / script | What Izi says - a transcript |
| Caption | The original caption |
| Topic | A few words, e.g. "coach emails", "showcases", "parents" |
| Original video file | Drive link to the full-quality file |
| B-roll used | What's on screen, in a few words |

**How to build it:**
1. Pull every post from the last 2 years on both accounts, with numbers. Use Metricool's export,
   or Meta Business Suite -> Insights -> Content -> Export.
2. Sort by views.
3. Keep posts in the top 10% for that account, or at least 3x that account's median views.
   That should be roughly 30-60 posts per account.
4. Izi takes a quick look and deletes anything she never wants reused.

### 2. The original video files

Full-quality versions of every library post in one Drive folder, e.g. **"Viral Library -
Originals"**, with one subfolder per account. Name each file with its post date so it matches
the sheet.

### 3. The B-roll library

One Drive folder of Izi's B-roll, with subfolders by type: training, games, Izi on camera,
recruiting and campus, lifestyle. Add a short note next to any clip that shows a student,
saying whether parent consent is on file.

### 4. The hook styles

Already in Part 1. The full list with examples is in `content-plan-dashboard/playbooks/hooks.md`.
